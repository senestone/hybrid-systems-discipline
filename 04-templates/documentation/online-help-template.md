# 1. Applicability

Online help is required when embedded guidance materially improves correct use of an interactive system.

If online help is not applicable, document the justification in the System Documentation Package.

# 3. Help Content Requirements

Help content SHALL:

- Use user-facing terminology
- Match current UI labels
- Explain required actions
- Provide recovery guidance for common errors
- Avoid contradicting the User Guide
- Avoid exposing privileged operations to non-admin users

Outdated online help is a documentation defect.

---

# 4. Online Help Verification

Confirm:

- Help links resolve
- Help content renders correctly
- UI labels match current implementation
- Role-specific help is access-appropriate
- Help content version aligns with release version

Broken or misleading help SHALL block documentation approval.
